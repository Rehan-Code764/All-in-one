# 🛒 Amazon Clone

A frontend Amazon Clone website created using HTML and CSS.  
This project recreates the look and layout of an e-commerce shopping website with a navigation bar, search section, product categories, deals, and product cards.

## ✨ Features

- Amazon-style navigation bar
- Search bar with category selection
- Account & Lists section
- Returns & Orders section
- Shopping cart section
- Navigation menu
- Product categories
- Today's Deals section
- Product cards with images
- Responsive and clean UI
- Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Image Assets
